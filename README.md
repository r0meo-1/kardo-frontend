## Запуск

Нужен Node.js 22 и npm:

```bash
npm ci
npm start
```

Dev-сервер открывается на `http://localhost:3000`. Production-сборка:

```bash
npm run typecheck
npm run lint:ts
npm run lint:css
npm run build:prod
```

Результат — каталог `build`. При публикации сервер должен отдавать
`index.html` для неизвестных путей, чтобы работала прямая ссылка на `/test`.

После совместимых обновлений `npm audit` сообщает о пяти умеренных находках
в цепочках React Router и webpack-dev-server/SockJS/UUID; высоких и критических
находок нет. Их устранение требует отдельной проверки обновлений основных
версий. CI проверяет зависимости с порогом `high`, типы, линтеры и сборку.
